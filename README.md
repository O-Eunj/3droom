# 방꾸미기 프로젝트 프로토타입

기존 React/Vite 프로젝트의 소개·응모 흐름을 유지하면서 방꾸미기 화면을 수정했습니다.

## 수정한 기능

- 나무 바닥, 두꺼운 외벽, 창문, 현관, 고정 주방, 우측 상단 화장실이 있는 2D 평면도
- 기본 가구: 침대, 책상, 1인용 소파, 러그, 조명
- 앱 전용 가구: 오늘의 p!ck 침대, 오늘의 p!ck 러그
- 가구 추가 목록 마지막의 ‘더 다양한 가구 추가’ 버튼과 앱 다운로드 안내
- 선택한 가구에만 회전·삭제 도구 표시. 빈 바닥 클릭이나 완료 버튼으로 선택 해제
- 드래그 이동, 90도 회전, 방향키 이동(5cm), R키 회전, Delete키 삭제, Escape키 선택 해제
- 러그는 다른 가구 뒤에 표시되므로 침대나 소파 아래에 배치 가능
- 5·7·10평에 맞춘 실제 치수 비율, 회전 후 벽과 주방·화장실 내부로 벗어나지 않도록 배치 보정

평수는 화장실을 포함한 내부 바닥 면적 기준이며, 제공된 이미지를 참고한 예시 구조입니다. 실제 건축 도면을 측정한 결과는 아닙니다. 가구 그림은 외부 이미지 없이 SVG로 작성했습니다. 가구끼리의 겹침과 문이 열리는 공간은 사용자가 조정할 수 있습니다.

가구 치수(cm): 침대 110×200, 책상 120×60, 1인용 소파 80×85, 러그 150×200, 조명 35×35. 앱 전용 가구는 예시 치수이며 실제 상품 연동은 아닙니다.

## 검증

`pnpm test` 또는 `node scripts/room-geometry.test.mjs`로 2,160개 배치 조합을 검사합니다.

이번 작업 환경에서는 하위 프로세스 실행 제한(EPERM)으로 표준 Vite 빌드를 완료하지 못했습니다. 대신 같은 설치 의존성의 esbuild 실행 파일과 Tailwind CLI로 정적 번들을 생성했고, 브라우저에서 가구 추가·드래그·회전·선택 해제·삭제·평수 변경·앱 안내를 확인했습니다. 원본 Vite 설정과 GitHub Actions 배포 설정은 유지했습니다.

소개 화면의 이벤트 내용, 응모 완료 화면, 3D 안내는 기존 프로토타입 흐름입니다. 실제 응모 전송·상품 연동·3D 렌더링 서버는 포함하지 않습니다. 새로고침하면 배치가 초기화됩니다.

## 실행

Node.js와 pnpm이 설치된 컴퓨터에서 이 폴더를 연 뒤 다음 명령을 실행합니다.

```bash
pnpm install
pnpm run dev
```

터미널에 표시되는 주소를 브라우저에서 열면 로컬에서 확인할 수 있습니다.

## GitHub Pages 배포

저장소의 **Settings → Pages → Build and deployment → Source**에서 **GitHub Actions**를 선택합니다. 이후 `main` 브랜치에 변경 사항을 올리면 GitHub Actions가 웹사이트를 빌드하고 배포합니다.

배포 주소: `https://O-Eunj.github.io/3droom/`

배포 작업이 완료되면 QR 이미지를 `https://O-Eunj.github.io/3droom/website-qr.png`에서 받을 수 있습니다. 로컬에서 별도로 만들 때는 아래처럼 실행합니다.

```bash
pnpm run qr https://O-Eunj.github.io/3droom/
```

QR 이미지가 `dist/website-qr.png`에 만들어집니다. 이 PNG를 발표 자료나 인쇄물에 넣으면 QR 스캔으로 웹페이지에 접근할 수 있습니다.
